# Codeforces Problem Solutions

This repository contains my solutions to problems from [Codeforces](https://codeforces.com/), one of the most widely used competitive programming platforms. The problems here are primarily from Division 2 and Division 3 rounds, covering a range of difficulty levels and topic areas. I use this repository to track my progress, keep my solutions organized, and revisit problems when needed.

---

## Overview

Competitive programming requires consistent practice across a variety of problem types. This repository reflects that process. Each file corresponds to a single Codeforces problem, named after the problem's ID and title to make it easy to locate a specific solution. The solutions are written in C, C++, and occasionally Python, depending on what was appropriate for the problem at hand.

The primary language used is C++, which accounts for the majority of the solutions here. Some earlier problems were solved in C, and a small number of problems have Python solutions as well.

---

## File Naming Convention

Each solution file follows a consistent naming format:

```
<ProblemID>_<Problem_Title>.<extension>
```

For example:

- `1A_A_Theatre_Square.c` — Problem 1A, Theatre Square, solved in C
- `263A_Beautiful_Matrix.c` — Problem 263A, Beautiful Matrix, solved in C
- `A_Array_Coloring.cpp` — solved in C++
- `A_Catch_the_Coin.py` — solved in Python

This makes it straightforward to search for a problem by its Codeforces ID or by its title.

## How to Run a Solution

All solutions are standard single-file programs and can be compiled and run locally.

**For C or C++ files:**

```bash
gcc solution.c -o solution && ./solution
# or
g++ solution.cpp -o solution && ./solution
```

**For Python files:**

```bash
python3 solution.py
```

Input can be provided via standard input (stdin), which is how Codeforces problems are structured. Most online judges, including Codeforces, accept input from the terminal or from redirected files.

## Tools and Setup

- **Editor:** Visual Studio Code (`.vscode` configuration is included in the repository)
- **Competitive Companion Plugin:** The `.cph` folder contains test case data managed by the Competitive Programming Helper (CPH) extension for VS Code, which allows running test cases locally before submission
- **Compiler:** GCC / G++ for C and C++, Python 3 for Python files

If you are practicing Codeforces problems yourself and find a solution here useful as a reference, feel free to look through it. However, I would encourage attempting the problem on your own first before consulting any solutions.
